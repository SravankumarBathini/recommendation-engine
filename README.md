# 🛒 Unsupervised Market Basket Recommendation Engine

## 🏢 Business Case Overview
This repository contains a production-grade **Unsupervised Machine Learning Engine** engineered to discover and extract hidden human behavioral patterns across raw, unlabeled retail transaction ledgers.

Unlike standard supervised pipelines that rely on strict true/false labels, this engine evaluates multi-dimensional transactional spaces to reveal product association matrices. By automating the extraction of these consumer insights, e-commerce platforms can deploy calibrated digital cross-sell prompts, and brick-and-mortar stores can structurally optimize shelf layout architectures to maximize average order value (AOV).

---

## 🏗️ Systems Architecture Map
The application is built using a fully modular, sandboxed pipeline layout:

1. **High-Speed Ingestion Matrix:** Utilizes the multi-threaded, Rust-backed **Polars** engine paired with **PyArrow** to process 5,000 text-based receipt registers cleanly without interpreter block overheads.
2. **Boolean Vector Realignment:** Transforms variable-length string categories into structural, static-width binary tensors through an optimized **Transaction Encoder Matrix**.
3. **Apriori Pruning Optimization Layer:** Implements the **Apriori Pruning Principle** to track frequent combinations crossing a strict 5.00% global support popularity gate, eliminating millions of useless computational cycles.
4. **Behavioral Physics Topography:** Calculates directional predictive rules through a multi-metric verification loop utilizing **Support, Confidence, Lift, and Asymmetric Conviction** to separate genuine trends from random noise.

## 🚀 Execution & System Deployment Guide
To execute this model pipeline on your local machine terminal environment, run these PowerShell scripts:

```powershell
# 1. Clone your repository framework and move inside the project directory
cd recommendation-engine

# 2. Re-establish your isolated package environment sandbox
python -m venv rec_env
.\rec_env\Scripts\Activate.ps1

# 3. Build the core architecture package dependencies in a single pass
pip install -r requirements.txt
```
